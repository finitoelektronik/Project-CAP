# Profil kode rekening berversi

Accounting Lite menggunakan enam segmen kode rekening yang dipisahkan titik, dengan profil awal `2.2.2.2.2.4`. Master 888 dapat memperbesar panjang segmen untuk rekening baru, tetapi kode lama tidak pernah ditulis ulang; relasi induk dipilih secara eksplisit agar variasi seperti `… .00` dan `… .000` tidak saling bertabrakan atau memutus jurnal historis.
