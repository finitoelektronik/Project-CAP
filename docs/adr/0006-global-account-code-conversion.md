# Konversi global kode rekening ke 2.2.3.3.3.4

Accounting Lite mengonversi seluruh kode rekening dan referensinya dari pola `2.2.2.2.2.4` ke `2.2.3.3.3.4` dalam satu transaksi atomik. Keputusan ini dipilih agar kapasitas rekening pada segmen menengah mencukupi tanpa mempertahankan dua format kode yang berbeda; saldo, jurnal, dan relasi barang harus tetap identik setelah verifikasi.
